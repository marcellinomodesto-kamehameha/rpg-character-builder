About This Application

The RPG Character Builder is a web application designed to help adventurers create and explore characters for their next fantasy adventure.

Browse character classes, review class information, and roll ability scores using the built-in ability roller.

Features

  • Browse available character classes
  • View detailed class information
  • Roll ability scores with different dice sizes
  • Navigate easily between application sections
